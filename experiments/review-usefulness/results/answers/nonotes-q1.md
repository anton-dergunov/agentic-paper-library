This is drawn from the library only (about 20 papers, the newest from July 2026); I did not search the web. The short version: research has moved from "overwrite the old fact" to "keep it, but label it as superseded", and the evidence says the hard failures now sit downstream of storage.

**The problem, by example.** A user says "I live in Seattle", then months later "setting up utilities in my Austin apartment". Nothing negates the first fact explicitly. The old address is still the right answer to "where did I live before?" and the wrong answer to "where should this ship?". A-TMA calls the resulting mix-up "ghost memory": old, current and transition facts coexist and reach the answer model without roles ([A-TMA, p. 1](http://pdf.invalid/llm/memory/agent/A-TMA.%20Decoupling%20State-Aware%20Memory%20Failures%20in%20Long-Term%20Agent%20Memory.pdf?dest=section.1&page=1)).

**How systems handle it (external memory)**

- **Destructive update.** Mem0 has an LLM pick ADD / UPDATE / DELETE / NOOP per new fact, deleting contradicted memories ([Mem0, p. 3](http://pdf.invalid/llm/memory/agent/Mem0.%20Building%20Production-Ready%20AI%20Agents%20with%20Scalable%20Long-Term%20Memory.pdf?dest=subsection.2.1&page=3)). Memory-R1 trains that choice with RL because the untrained manager misreads complementary facts (two dogs adopted in different sessions) as a contradiction ([Memory-R1, p. 1](http://pdf.invalid/llm/memory/agent/Memory-R1.%20Enhancing%20Large%20Language%20Model%20Agents%20to%20Manage%20and%20Utilize%20Memories%20via%20Reinforcement.pdf?page=1)).
- **Invalidate, don't delete.** Zep/Graphiti stores four timestamps per fact (when it was true, when the system learned it) and closes the validity interval of a contradicted edge ([Zep, p. 3](http://pdf.invalid/llm/memory/agent/Zep.%20A%20Temporal%20Knowledge%20Graph%20Architecture%20for%20Agent%20Memory.pdf?dest=subsubsection.2.2.3&page=3)). Mem0's graph variant also marks relations invalid rather than removing them.
- **Explicit state roles.** A-TMA argues timestamps are not enough. It marks records active / superseded / transition, links them, infers whether the query wants the current or historical state, and labels evidence for the answer model ([A-TMA, p. 6](http://pdf.invalid/llm/memory/agent/A-TMA.%20Decoupling%20State-Aware%20Memory%20Failures%20in%20Long-Term%20Agent%20Memory.pdf?dest=subsection.4.3&page=6)).
- **Decay and probability.** MemoryBank fades memories on an Ebbinghaus curve; Belief Memory keeps several candidate conclusions with probabilities so a wrong one can be revised. Decay removes unused facts, not wrong ones.

**What the evidence says**

- **Temporal metadata alone does not fix answers.** On A-TMA's benchmark, Graphiti retrieves supporting evidence 81% of the time but gets 42.5% conflict accuracy; adding state labels raises it to 72.5% ([p. 1](http://pdf.invalid/llm/memory/agent/A-TMA.%20Decoupling%20State-Aware%20Memory%20Failures%20in%20Long-Term%20Agent%20Memory.pdf?dest=section.1&page=1)). In Zep's own table, knowledge-update accuracy falls from 76.9% to 74.4% with gpt-4o-mini against its baseline ([p. 7](http://pdf.invalid/llm/memory/agent/Zep.%20A%20Temporal%20Knowledge%20Graph%20Architecture%20for%20Agent%20Memory.pdf?dest=subsubsection.4.3.2&page=7)).
- **Graphs still lead on direct fact revision.** An 11-system comparison finds Zep best on LongMemEval knowledge-update, and append-only stores returning "hallucinations of the past" ([Are We Ready, p. 9](http://pdf.invalid/llm/memory/agent/Are%20We%20Ready%20For%20An%20Agent-Native%20Memory%20System.pdf?dest=subsection.4.3&page=9)).
- **Recall quality says nothing about forgetting.** ForgetEval tests supersede, expire and purge across 13 configurations. Deterministic stores reach about 70% on adversarial cases, and an LLM called at mutation time about 93% ([ForgetEval, p. 6](http://pdf.invalid/llm/memory/agent/Control-Plane%20Placement%20Shapes%20Forgetting.%20An%20Architectural%20Study%20of%20Agent%20Memory%20Across%20Thirteen.pdf?dest=subsection.5.3&page=6)).
- **A correct store does not guarantee correct behaviour.** On the Stale benchmark, a system resolves the user's current state 91% of the time but adapts open-ended responses only 32% of the time. Checking the draft's claims misses this because the stale assumption is unstated; StateAuditor checks from changed state to draft instead ([StateAuditor, p. 1](http://pdf.invalid/llm/personalization/methods/When%20Memory%20Updates%20but%20Behavior%20Does%20Not.%20Repairing%20Implicit%20Stale%20Dependencies%20in%20Personalized.pdf?dest=section.1&page=1)).
- **Models themselves revert to the old value.** On HorizonBench the best of 25 models scores 52.8%, and over a third of errors on evolved preferences pick the originally stated value ([HorizonBench, p. 1](http://pdf.invalid/llm/personalization/benchmarks/HorizonBench.%20Long-Horizon%20Personalization%20with%20Evolving%20Preferences.pdf?page=1)).

**Facts in the weights.** MEMIT edits thousands of facts directly in the weights; MemoryLLM and Larimar add an updatable memory pool instead. The critique in [Fundamental Problems With Model Editing, p. 4](http://pdf.invalid/llm/memory/parametric/Fundamental%20Problems%20With%20Model%20Editing.%20How%20Should%20Rational%20Belief%20Revision%20Work%20in%20LLMs.pdf?dest=section.3&page=4) is that editing is belief revision: nobody can specify which downstream beliefs should change, and there is no reason a small finetune maps to a learned revision process. MemoryAgentBench's FactConsolidation task has agents override facts with newer contradicting ones; the authors call performance "drastically low" ([p. 10](http://pdf.invalid/llm/memory/benchmarks/Evaluating%20Memory%20in%20LLM%20Agents%20via%20Incremental%20Multi-Turn%20Interactions.pdf?dest=subsubsection.4.3.4&page=10)).

**Weakly supported**

- **A-TMA:** gains depend on the host system, and its LoCoMo F1 values are very low in absolute terms (0.08 to 0.16).
- **ForgetEval:** single author, whose own store is one of the systems tested; scoring is substring match. Graphiti's 7% there is a missing-primitives mismatch, not a fair ranking.
- **Benchmarks generally:** almost all are synthetic, and several rely on LLM-drafted cases.

**Gaps in the library.** The Stale benchmark (Chao et al. 2026), MQuAKE and Memora are cited by these papers but not held. Say if you want them added.
