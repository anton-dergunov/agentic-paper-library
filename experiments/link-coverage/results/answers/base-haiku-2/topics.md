**The paper doesn't name a default.** It's a 2024 survey that maps neural topic models (NTMs) and their evaluation, but it never benchmarks methods against each other or recommends one. So the answer below is my reading of what it implies, not a finding it states.

- **Its starting point is the VAE-based NTM** (NVDM, ProdLDA). It treats this as the basic model that the rest build on, with a logistic-normal prior and an encoder/decoder trained by the ELBO ([p. 6](http://pdf.invalid/nlp/topic-models/A%20Survey%20on%20Neural%20Topic%20Models.%20Methods%2C%20Applications%2C%20and%20Challenges.pdf?page=6)).
- **The newest approach it covers is FASTopic**, which drops the VAE and uses optimal transport between document, topic and word embeddings. It presents this as "a neat and efficient paradigm" ([p. 10](http://pdf.invalid/nlp/topic-models/A%20Survey%20on%20Neural%20Topic%20Models.%20Methods%2C%20Applications%2C%20and%20Challenges.pdf?page=10)). The library has the FASTopic paper, which I haven't read in this session.
- **Embedding-based models** such as ETM ([p. 7](http://pdf.invalid/nlp/topic-models/A%20Survey%20on%20Neural%20Topic%20Models.%20Methods%2C%20Applications%2C%20and%20Challenges.pdf?page=7)) and PLM-based NTMs ([p. 8](http://pdf.invalid/nlp/topic-models/A%20Survey%20on%20Neural%20Topic%20Models.%20Methods%2C%20Applications%2C%20and%20Challenges.pdf?page=8)) are the other mainstream options it describes.
- **Clustering methods (Top2Vec, BERTopic) and LLM-based TopicGPT don't give doc-topic distributions** ([p. 9](http://pdf.invalid/nlp/topic-models/A%20Survey%20on%20Neural%20Topic%20Models.%20Methods%2C%20Applications%2C%20and%20Challenges.pdf?page=9)). If you need θ for downstream features, rule them out.
- **For evaluation, the paper recommends CV coherence computed with Palmetto** ([p. 4–5](http://pdf.invalid/nlp/topic-models/A%20Survey%20on%20Neural%20Topic%20Models.%20Methods%2C%20Applications%2C%20and%20Challenges.pdf?page=5)). It also argues perplexity is a poor guide to topic quality.

**My take:** if you need one default today, the paper points toward an embedding-based model with pretrained document embeddings, and FASTopic is the most recent option it describes. That is a judgement from the survey's direction, not a result it reports. The survey is dated June 2024, so it can't tell you what is best in October 2026. The library's own "Is Automated Topic Model Evaluation Broken" paper bears on how you'd compare candidates, since it questions coherence as the yardstick. I'd check the FASTopic note and that paper before committing to a default. I can read them next if you want.
