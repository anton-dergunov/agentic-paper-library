What shippedpaperlib add-pdf
docling reads the layout

Headings, tables, figures and reading order. Words and numbers come from the PDF's own text layer, so a number cannot be misread.

A model reads each equation

docling marks where the equations are; each is cropped from the page image and read by surya, marker's model, in about two seconds.

Inline maths is read again

A paragraph set partly in a maths font is read from the page the same way. The reading is kept only if it has the paragraph's words and every number.

q ∈ R n → $q \in \mathbb{R}^n$
Tables and code that are images in the PDF are read by OCR. A paper converted this way says so at its top, and gets the HTML conversion once arXiv renders it.

Known limits
Headings set as run-in bold text are not found. A caption can land a paragraph from its table. Plots keep their image but not their numbers. Papers arrive one or two a day, so precision was chosen over speed.
