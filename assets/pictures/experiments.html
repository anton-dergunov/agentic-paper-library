What should the agent read: Markdown, the PDF or its text?(experiments/reading-formats)
51 questions on single papers: the PDF 51, its text layer 43, the converted Markdown 43; the eight lost are values drawn in plots. Across papers, the text layers answered as well as the library, at $0.30 a question against $0.42.
The PDF’s text layer, with the PDF beside it
Does the agent open the page when the text lacks a value?(experiments/reading-formats)
With the PDF beside its text, unprompted: the page opened for 9 of 9 values drawn in figures and for 0 of 6 questions the text answers, at about $0.11 a question.
Rely on it, and check it on each Claude Code release
Which converter for web articles?(experiments/web-articles)
Three converters on three articles. Defuddle kept 94–99% of the text, every equation as TeX and the footnotes; Readability printed each formula twice; Trafilatura dropped every heading.
Defuddle, on the page as Chrome renders it
Which model files a paper?(experiments/skill-models)
60 papers, one request each. A blind judge graded the folder best for 57 with Opus, 53 with Sonnet and 49 with Haiku, in about 4 seconds, against 55 seconds for a skill session.
Sonnet, one request a paper
Which model reads a paper into its note?(experiments/reading-models)
Five models were tested as the reader on the same six papers. Errors found when their notes were checked against the papers: Opus 1, Sonnet 6, Gemini Pro 7, Gemini Flash 9, Haiku 35.
Opus reads, one request a paper
Answer from the review, or from the papers?(experiments/review-usefulness)
Starting from the review, then checking the paper: 4.7 wrong statements over three questions and 22% fewer tokens. Without reviews: 6.3 wrong; without reviews or notes: 3.3. The answers were no more complete.
Start from the review, and check the paper before stating a number
