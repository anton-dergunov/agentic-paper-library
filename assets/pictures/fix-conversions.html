3Converted again

Every paper with the same problem is corrected at once. A note is rewritten only when the paper’s key content was affected.

An example: a digit nobody could seeAuthors pad a number with an invisible digit so that a column lines up. The PDF hides the digit; the HTML source still carries it, and it was printed. One fix in the converter removed it from 29 papers.
