3Converted again

Every paper with the same problem is corrected at once. A note is rewritten only when the paper’s key content was affected.

What a note records about the conversion
conversion: ok
Nothing wrong that matters to the content.
conversion: equation 4 is garbled (p. 5)
A flaw and its page. The note still stands.
conversion: key-content-broken: the scores in Table 2 have a digit too many (p. 7)
The paper’s findings rest on the broken part. Only these papers are read again after the fix.
An example: a digit nobody could see Authors pad a number with an invisible digit so that a column lines up. The PDF hides it; the HTML source still carries it, and it was printed. One fix in the converter removed it from 29 papers.
